# Phase 03 — gap-directed mode, and the CLAUDE.md rule

```yaml
phase: 3
claim: >
  The knowledge-layer rule terminates in a queued candidate rather than an
  apology, and the skill never writes to the pool while doing it.
cites: lab/reinforce/PRD.md#two-entry-modes-one-machine
build: gap-directed mode in SKILL.md + CLAUDE.md § Answering from the knowledge layer
failing_check: >
  node guards/reinforce.mjs && git diff --quiet -- 'resources/[0-9][0-9]-*.md'
done_when: >
  A run against a question the pool cannot answer produces at least one queue
  entry with `axis: gap` and `targets: G<n>`, and no numbered note changed.
type: build
```

## The loop this closes

The `CLAUDE.md` rule says: *if the question has a determinate answer and the
pool is silent, stop and say so.* Without this phase that rule terminates in an
apology — it tells you what you don't have and offers no way to get it, which
makes it a rule you route around within a week.

Gap-directed mode is the same search machinery pointed at a question instead of
a note. The axes collapse to three: what would answer this, who disagrees about
it, and has anyone measured it.

## The second half of the failing check

`git diff --quiet -- 'resources/[0-9][0-9]-*.md'` enforces the PRD's hardest
non-goal: **`/reinforce` never writes to the pool.** It writes to the queue and
nowhere else, and `/intake` remains the only door. A check that only looked at
the queue would miss the failure that actually matters.

## The honest part: the rule itself is prose-tier

Per [lesson 00](../../../workshop/lessons/00-enforcement-map/README.md)'s
classification, the `CLAUDE.md` knowledge-layer rule sits in the **weakest
tier**, and its failure is **silent**. Nothing detects an answer that skipped
`resources/` and came from training data in a confident voice.

This is not mitigated. It is classified, because pretending otherwise would
repeat the exact mistake this repo exists to fix — and because
[resource 12](../../../resources/12-long-horizon-control.md) is explicit that
self-audit cannot be requested from inside the prompt.

What *does* help, and is the honest reason to expect any compliance at all:

| | |
|---|---|
| **Cheap compliance** | The pool's weak points are one grep over frontmatter. A rule that's expensive to follow gets routed around; this one costs a `grep`. |
| **A terminating action** | The rule's failure branch ends in `/reinforce`, not in an apology. |
| **A visible artifact** | Citations name a note and section, so an *uncited* answer is conspicuous to the reader even though nothing blocks it. |

That third one is the closest thing to enforcement available here: not a gate,
but a convention that makes the violation legible to a human who cares. Say so
in `CLAUDE.md` rather than implying the rule is stronger than it is.

## What would make this enforceable later

A `Stop` hook that fails a turn whose answer cites no note when
`resources/` contains matching tags. Genuinely hard — it needs to judge
relevance, which is the LLM-guard problem again. Recorded here as a known limit
rather than a plan, and a candidate for lesson 02 once hooks exist.
