## The instruction the whole phase rests on

> **Search the note's weak points, not its topic.**

Searching the topic returns more of what the pool already has. The four axes
are defined in [PRD.md](../PRD.md#the-four-axes) by *what they search*, and
that definition is the load-bearing part — axis 2 in particular searches the
note's **Problem**, never its Mechanism, because the mechanism finds people who
already agree.

## Zero is a result

Every applicable axis appears in the run record even when it returned nothing.
A run that silently drops its empty axes is indistinguishable from one that
never tried them — and "nobody has measured this" is a finding that
*strengthens* the note's caveat rather than a failure of the search.

## The control, and why the guard doesn't judge it

The run record carries a `control` section: the same note searched by **topic**,
and the overlap against the weak-point results.

The guard checks that the control **exists and reports a number**. It does not
check whether that number is good. Automating the judgment would be an LLM
guard grading its own search, which is
[resource 12](../../../resources/12-long-horizon-control.md)'s exact failure
mode. Forcing the evidence to be visible is the part a guard can honestly do;
reading it is stage 5's job.

## Run record

`lab/reinforce/runs/YYYY-MM-DD-<note>.md`:

```markdown
# reinforce 09 — YYYY-MM-DD

| Axis | Searched | Found | Queued |
|---|---|---|---|
| measured | <the query> | 3 | 2 |
| alternative | <the query> | 0 | 0 |
| opposing | <the query> | 1 | 1 |
| falsifier | <the query> | 0 | 0 |

## Control — topic search
query: <the topic query>
returned: <n> · overlap with weak-point results: <n>

## Judgment
<what the overlap says about whether the axes did anything>
```

## Stage-5 question

Attached to this phase specifically: **did weak-point search actually return
different candidates than topic search?** The guard forces the number to exist.
Only you can say whether it's good enough — and if the overlap is near-total,
the axes are decorative and the skill needs rethinking rather than shipping.
