# Phase 03 — the skill and the advocate pair

```yaml
phase: 3
claim: >
  A real brainstorm produces a session file and a correctly-tagged gap entry,
  without producing code.
cites: PIPELINE.md#build-order
build: .claude/skills/brainstorm/SKILL.md + .claude/agents/{idea-man,devils-advocate}.md
failing_check: >
  npm run guard && git diff --quiet -- 'lab/' 'guards/' 'tools/'
done_when: >
  A real session's artifacts pass every guard, and the diff shows nothing was
  implemented.
type: build
```

## The second half of the failing check is the important half

`git diff --quiet -- 'lab/' 'guards/' 'tools/'` enforces the PRD's hardest
non-goal: **`/brainstorm` never writes code.** A check that only validated the
session file would pass on a run that also quietly built the thing — which is
exactly the [G12](../../../GAPS.md) failure it exists to prevent, so a green
check that missed it would be worse than no check.

Same shape as `/reinforce` phase 03's "the pool must be unchanged" assertion.

## The advocate pair

Two subagents, spawned in one message so they run concurrently, each given the
idea and **nothing else**.

| | |
|---|---|
| `idea-man` | The happy path, what it enables at scale, the cheapest version that would still prove it |
| `devils-advocate` | The unpriced cost, what it breaks, the boring failure, and the case for not building it |

**Unconditional** — fixes the prior HIVE approach, which fired on request. Nobody
interrupts their own good mood to ask whether they're over-engineering, so the
trigger can't be self-report.

**Isolated** — [R13](../../../resources/13-epistemic-sandboxing.md). A critic
who has read the enthusiasm softens; an advocate who has read the objections
hedges. Two passes in one context produce mush wearing a debate's clothes.

Both are given `tools: Read, Grep, Glob` — no write access, at the harness tier
rather than by asking. An advocate that can edit files is not an advocate.

## Stage-5 question

**Did the pair change any outcome?**

If every session ends `verdict: gap` and the devil's advocate never talked anyone
out of anything, the pair is theatre and the isolation isn't buying what it
costs. The counter-evidence is one session that ended `declined` *because of*
something the advocate raised.

This cannot be answered from a commit. It needs several real sessions, and until
then the claim that this design works is exactly the kind of unverified assertion
the repo tags `inferred`.

## Partial payment on G13, not closure

[G13](../../../GAPS.md) wants a scope check that fires on **artifacts** — a lab
cut from a non-`observed` gap, a phase with no failing check. This one fires only
inside a conversation someone chose to start. The mechanism is proven here; the
trigger is still missing.
