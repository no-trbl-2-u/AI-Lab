# Phase 01 — `guards/gaps.mjs`: the spine gets validation

```yaml
phase: 1
claim: >
  A malformed gap entry is rejected before it reaches the spine, and the format
  tools/roadmap.mjs depends on cannot drift silently.
cites: GAPS.md#what-belongs-here
build: guards/gaps.mjs + guards/fixtures/gaps/spine-*.md
failing_check: node guards/gaps.mjs --fixtures
done_when: >
  Ten spine fixtures behave as specified — two pass, eight fail for one named
  reason each — and the real GAPS.md is green.
type: build
```

## Why this is first

`/brainstorm` writes into `GAPS.md`. Until this phase the spine had **zero
validation**, despite being the thing labs are cut from, resources point at, and
`ROADMAP.md` sorts by.

`tools/roadmap.mjs` already parses it and degrades *silently* when the format
drifts — a readiness marker it doesn't recognise renders as `—` rather than
erroring, and a template inside a code fence was reported as a real closed gap
until that was found by reading the output. Building a skill that writes entries
before the format is checked would industrialise that.

## The predicates

| # | Predicate |
|---|---|
| 1 | Heading matches `### G<n> — <title>` |
| 2 | IDs unique, and contiguous from G1 |
| 3 | ≥1 provenance tag from `stated` / `observed` / `delta` / `inferred` |
| 4 | A `**Closed when:**` clause exists |
| 5 | Readiness marker parses into a form `roadmap.mjs` recognises |
| 6 | `inferred` gaps carry their explicit unverified marker |
| 7 | Closed gaps carry a date **and** the check that proves closure |
| 8 | Code-fenced templates are not parsed as real entries |
| 9 | Repo-relative link destinations exist |

**Predicate 5 is the load-bearing one.** It converts `roadmap.mjs`'s silent
degradation into a loud failure, which is the whole reason this repo prefers
guards to prose.

## What it deliberately does not check

Whether a gap is **honestly** tagged. `observed` vs. `stated` is a judgment call,
and a guard claiming to check it would be an LLM grading its own work —
[R12](../../../resources/12-long-horizon-control.md)'s exact failure mode. The
guard checks that a tag is present and drawn from the fixed set, and stops.

Tag honesty stays a **prose** rule. `CLAUDE.md`'s enforcement table says so, and
the aggregate check (`grep '^provenance:' brainstorms/*.md` — is everything
coming back `stated`?) is documented in `brainstorms/README.md` as the thing a
human runs instead.

## Result

The first run against the real `GAPS.md` found **three defects**: G8, G9, and G10
carried no `Closed when:` clause. By `GAPS.md`'s own definition — "stated
concretely enough that you'd know when it closed" — those were topics wearing
gaps' clothes, and they'd been sitting on the spine unnoticed.

Fixed in this phase by writing the three closing conditions, which is the more
useful half of the work: each one forced a statement of what closure actually
looks like.
