# Rejected resources

Resources that went through `/intake` and were **not** kept. One line each.

Rejection is a decision, and an unrecorded decision gets re-litigated. If you
find a link here, you already read it and already said no — check the reason
before reopening it.

## Format

```
- YYYY-MM-DD — [title](url) — <reason>
```

Reasons worth using:

- `duplicate of NN` — says nothing resources/NN doesn't already say
- `secondary` — restates a primary source already in the pool
- `no actionable claim` — interesting, changes nothing we'd do
- `unfalsifiable` — claims without evidence or a way to check them
- `out of scope` — model training, fine-tuning, or below the harness layer
- `superseded` — true when written, no longer
