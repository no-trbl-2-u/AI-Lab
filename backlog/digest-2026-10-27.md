# Digest 2026-10-27

## Claude Code 2.1.311: late MCP servers reach subagents
- Source: https://code.claude.com/docs/en/changelog
- Type: news (Anthropic, Oct 26 2026)
- What: subagents can now use MCP tools from servers that finish connecting after the subagent starts. `SubagentStop` hooks no longer fire about twice a minute per running subagent. A skill run in a subagent no longer runs twice after a cloud restart.
- Why it matters: miserere-mei-deus's `kb-query` and `axio-query` MCP servers now reach subagents reliably. No repo uses `SubagentStop`.

## The Physical Cost of Context
- Source: https://www.alphaxiv.org/abs/2610.34763
- Type: research paper (Oct 26 2026)
- What: trimming history to the last 5 observations saved 33% of tokens but raised uncached prefill 608% and failed quality.
- Why it matters: editing cached history costs more than it saves. Keep loop context append-only.
